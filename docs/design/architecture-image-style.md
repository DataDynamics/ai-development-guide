# DataDynamics 설명 이미지 스타일

이 문서는 기존 제안서에서 사용한 **datadynamics architecture style 1.0**을 이 가이드의 학습용 그림에 적용하는 기준입니다. 원래 스타일 문서와 제안서의 메트릭 수집 아키텍처 PNG를 확인하여 배경·색상·패널·아이콘·연결선 원칙을 이어받습니다. 제안서의 시스템 구성이나 제품명은 이 가이드의 그림에 가져오지 않습니다.

스타일 확인일은 2026-10-08입니다. 기존 자료의 파일명은 `proposal/architecture-style.md`와 `proposal/12-metric-collection.png`입니다. 이 저장소에서는 아래 기준과 생성 프롬프트만으로 후속 그림을 작성할 수 있도록 정리합니다.

## 시각 원칙

| 요소 | 적용 기준 |
|---|---|
| 형식 | 불투명한 흰 배경의 PNG를 사용합니다. SVG로 대체하지 않습니다. |
| 화면 비율 | 제안서에 배치하기 쉬운 가로 16:9를 목표로 합니다. |
| 배경 | 가장자리까지 순백색 `#FFFFFF`를 사용합니다. |
| 색상 | 글자와 외곽선은 네이비, 보조 요소는 틸, 진행 화살표는 파란색을 사용합니다. 주황색은 실패·예외·재작업을 강조할 때 사용합니다. |
| 패널 | 얇은 테두리와 작은 모서리 반경을 사용합니다. 그룹 배경은 아주 옅은 파란색 또는 회색으로 제한합니다. |
| 사물 | 문서·폴더·모니터·돋보기·체크리스트·사람을 알아보기 쉬운 평면 그림으로 표현합니다. |
| 연결선 | 진행·분기·반복의 의미에 맞게 화살표를 연결합니다. 직각 연결선을 우선하고 교차를 줄입니다. |
| 글자 | 짧은 한국어 라벨을 사용하고, 도구명·파일명은 원문을 유지합니다. 긴 설명은 이미지 밖의 본문에 둡니다. |
| 여백 | 위아래에 흰 여백을 두고, 요소를 같은 격자와 간격에 맞춥니다. |
| 제목 | 이미지 전체 제목·부제·머리말·꼬리말·쪽 번호는 넣지 않습니다. 내부 패널의 제목과 단계 번호는 허용합니다. |
| 제외 요소 | 어두운 전체 배경, 네온, 과한 그라데이션, 장식용 3D, 의미 없는 로고·마스코트를 사용하지 않습니다. |

입문자가 작업 장면을 떠올릴 수 있도록 기존 제안서보다 한 화면의 정보를 줄이고 사물 그림을 크게 사용합니다. 같은 네모 상자에 이름만 바꾸는 대신, 폴더는 파일 범위, 터미널은 실행, 체크리스트는 검증이라는 역할을 나타냅니다.

## 본문과 연결하는 방법

1. 레슨의 `개념` 시작 부분에 그림을 배치합니다.
2. 대체 텍스트에 주체·순서·결과를 담습니다.
3. “그림 읽는 순서”에서 그림의 사물을 실제 작업과 연결합니다.
4. 그림에서 생략한 조건과 예외는 이어지는 텍스트·표·Mermaid에서 설명합니다.
5. 실제 도구 실행 방법은 기존 Claude Code·Codex 레시피에서 확인하도록 연결합니다.

그림은 개념 설명을 위해 생성한 이미지입니다. 제품의 실제 화면, 테스트 통과 증거, 측정된 성능 자료로 사용하지 않습니다. 권한 경계·신뢰 경계 그림도 특정 도구의 모든 동작을 표현하지 않으므로 세부 정책은 레슨의 설명과 설정을 함께 확인합니다.

## 파일과 재생성 기준

- 원본 PNG는 각 `modules/<모듈>/images/`에 보관합니다.
- [그림 목록](./illustrations.md)에서 원본 파일과 사용 레슨을 연결합니다.
- [생성 프롬프트](./illustration-prompts.json)의 `common_prompt` 뒤에 해당 그림의 `prompt`를 두 줄 띄워 붙이면 생성 시 사용한 입력이 됩니다. 수정본은 `revisions`의 마지막 프롬프트와 참조 이미지를 기준으로 확인합니다.
- 생성에는 내장 `image_gen` 도구를 사용합니다. 다른 프로젝트의 참조 이미지는 스타일을 확인하는 용도로만 사용하고, 새 이미지의 입력에는 해당 그림의 명세를 제공합니다.
- 프롬프트는 3840 × 2160을 목표로 요청합니다. 생성 도구의 실제 출력 크기는 [그림 목록](./illustrations.md)에 따로 기록하며, 4K 출력 여부와 구분합니다. 크기만 늘리는 후처리는 하지 않습니다.
- 새 버전을 만들 때는 한글 라벨, 화살표의 출발점과 도착점, 사람과 도구의 책임 범위, 본문과의 일치를 확인합니다.
- 이미지 생성일은 이미지 목록에 기록합니다. 이미지만 추가하거나 고쳤다고 레슨의 `last-verified`를 갱신하지 않습니다. 해당 날짜는 도구 기능을 다시 확인했을 때 갱신합니다.

## 제안서에서 사용합니다

원본 PNG를 내려받아 비율을 유지한 채 배치합니다. 슬라이드 제목과 설명은 슬라이드에서 따로 작성합니다. 글자가 작아지면 이미지를 한 장에 여러 개 넣지 않고 주제별로 나누며, 더 큰 출력이 필요하면 해당 프롬프트로 고해상도 재생성을 진행합니다.
