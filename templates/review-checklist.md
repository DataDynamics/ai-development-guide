# 리뷰 기준

- [ ] 요구사항과 diff가 대응하며 범위 밖 변경이 없는지 확인합니다.
- [ ] 계약의 입력·출력·오류·권한·호환성이 유지되는지 확인합니다.
- [ ] 데이터 누락·중복·동시성·재시도에 영향을 주는지 확인합니다.
- [ ] 테스트가 실제 동작을 확인하고 구현의 오류를 그대로 복제하지 않는지 확인합니다.
- [ ] 검사 대상 revision과 실제 검증 증거가 일치하는지 확인합니다.
- [ ] 필수 테스트의 skip·검증 우회·환경 의존성을 확인합니다.
- [ ] 사용자 문서·계약·운영 절차 갱신이 필요한지 확인합니다.

각 지적은 `심각도 / 파일·위치 / 재현 조건 / 영향 / 수정 제안`으로 남깁니다. 추측은 추측으로 표시합니다. 발견한 결함이 없으면 확인한 범위와 미검증 영역을 보고합니다.
