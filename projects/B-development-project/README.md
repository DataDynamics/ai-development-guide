# Project B — 개발 프로젝트 (TaskFlow)

팀 업무 관리 서비스 TaskFlow(웹 + API + 워커 + CLI)를 3~5만 라인 규모로 개발합니다.

## 실습 시작

[단계별 실행 가이드](../../docs/workflow/README.md)와 [템플릿 적용 순서](../../templates/README.md)를 별도의 개발 저장소에 적용합니다. B0·B1 산출물을 준비한 뒤 [상태 필터 기능 예제](../../docs/workflow/taskflow-example.md)를 참고해 작은 기능 하나를 구현·검증합니다. 라인 수는 학습용 규모 목표이며 실제 완료는 요구사항과 검증 증거로 판단합니다.

| 실행 가이드 | 연결할 마일스톤 | 확인할 산출물 |
|---|---|---|
| Step 0~1, 4 | B0 | 지침·저장소 구조·실행 환경·검증 전략 |
| Step 2~3, 5 | B1 | PRD·설계·계약·Task와 의존성 |
| Step 6~7 | B2~B3 | 계획·구현·테스트·실제 검증 기록 |
| Step 8 | B4 | 교차 리뷰·수정·사용자 흐름 검증 |
| Step 9 | B7 | 릴리스 상태·지표·핸드오프·회고 |

아래 개별 마일스톤 본문은 아직 작성 예정이며, 연결된 실행 가이드는 공통 절차를 제공합니다. 이 문서 저장소에는 실행 가능한 TaskFlow 서비스가 포함되지 않습니다.
